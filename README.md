# Arcify

Arc-style persistent favorites, tab groups, and last-used tab switching for Google Chrome.

Arcify is a small, local-first Chrome extension that makes Chrome behave more like Arc without replacing Chrome's native tab UI.

## Features

- **Persistent pinned tabs**  
  Pin a site once and Arcify keeps it pinned across normal Chrome windows.

- **Profile-local favorites**  
  Favorites are stored with `chrome.storage.local`, so each Chrome profile maintains its own Arcify state.

- **Persistent tab groups**  
  Save named Chrome tab groups and restore them in new windows.
